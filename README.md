# 北九州海岸線自駕行程

以佐賀機場為起終點的互動式自駕行程頁，包含每日停靠點、地圖定位與 Google Maps 駕車路線。

開啟 [`index.html`](index.html) 即可使用。地圖底圖由 OpenStreetMap 提供；Google Maps 連結會依當日停靠點建立駕車路線。海上活動與營業時間請以當日公告為準。

## GitHub Pages

可在 GitHub repository 的 **Settings → Pages**，選擇從 `main` 分支的根目錄發布。發布前請確認行程日期、景點與住宿位置適合公開；公開網站上的資訊任何人都可以瀏覽。

私人航班、租車與住宿確認文件及本機總覽不屬於網站內容，已由 `.gitignore` 排除。
